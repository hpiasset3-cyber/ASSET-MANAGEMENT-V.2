ASSET MANAGEMENT PWA - REPORT BA SO
====================================

Isi paket:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Instalasi GitHub Pages:
1. Ekstrak ZIP.
2. Upload seluruh isi hasil ekstrak ke root repository GitHub.
3. Buka Settings > Pages.
4. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
5. Buka URL GitHub Pages melalui Chrome Android.
6. Pilih Instal aplikasi / Tambahkan ke layar utama.

Catatan:
- Kamera dan lokasi membutuhkan HTTPS.
- Pengguna harus menekan Izinkan minimal satu kali.
- Data disimpan lokal pada perangkat menggunakan IndexedDB.
- Report BA SO mengikuti filter Estate dan jumlah baris mengikuti data verifikasi.
- Buka aplikasi satu kali saat online agar sumber eksternal ikut tersimpan untuk penggunaan berikutnya.
